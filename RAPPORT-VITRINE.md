# Rapport · Vitrine testeurs Bylux (branche feat/vitrine-testeurs)

- **Fait** : nouveau site vitrine à la même adresse `/testeurs/` (`?m=…` fonctionne toujours, il est simplement ignoré). Mobile d’abord, fond sombre néon violet/bleu repris du vrai logo Bylux Studio (`stone-to-stars/branding`), accroche « Joue à nos jeux avant tout le monde », 3 étapes avec pictos animés, 8 cartes de jeux (bannière réelle, icône, genre, badge d’âge, compteur X/12 + jauge, boutons « Devenir testeur », « Installer », « Jouer sur le web (iPhone / PC) » ou « bientôt » grisé sans lien), FAQ (pas encore testeur, iPhone, 14 jours, mauvais compte) et pied de page.
- **Données** : jeux, liens d’inscription/Play/web, compteurs et âges repris tels quels de l’ancienne page (Lockdown 11 → Bazaar 1). Lockdown : site non joignable depuis le KVM, donc son icône en grand sur fond flouté. Toutes les autres images sont les vraies bannières store converties en WebP (10 à 58 Ko).
- **Stack** : Vite + JS vanilla, sources dans `src-vitrine/` ; `npm run build` régénère `testeurs/` sans toucher à `testeurs/jeux.json`. `npm run images` reconvertit les bannières, `npm run verifier` lance Playwright, `node outils/lighthouse.mjs` lance l’audit (avec `npx vite preview --port 4174` démarré).
- **FR/EN** : selon la langue du navigateur, avec un bouton de bascule mémorisé (`localStorage`) et `?lang=en` possible. Aucune requête vers un tiers, aucune police externe, aucun traceur.
- **Mettre à jour `testeurs/jeux.json` (SANS rebuild)** : changer `"testeurs": N` du jeu, et `"maj": "AAAA-MM-JJTHH:MM"` (ex. `"2026-11-16T09:30"`), qui donne l’affichage « mis à jour le 16 novembre à 9 h 30 ». L’ordre des cartes est celui du fichier. Un lien web qui ouvre : remplacer `"web": null` par `"web": "https://…"`. La page relit le fichier sans cache (`no-cache`) à chaque visite. Vérifier que le JSON reste valide (virgules, guillemets).
- **Poids** : index.html 7,1 Ko gzip (CSS inclus), JS 4,5 Ko gzip, jeux.json 5 Ko. Page mobile complète ≈ 216 Ko d’après Lighthouse, images en lazy loading sauf la première. Dossier `testeurs/` : 552 Ko.
- **Lighthouse mobile** : Performance 100, Accessibilité 100, Bonnes pratiques 100 (FCP/LCP 0,7 s, TBT 0 ms, CLS 0,008). Le SEO à 58 est voulu : la page garde `noindex`, comme avant.
- **Playwright** à 360×640, 390×844, 412×915, 1280×800 (et 390×844 en anglais) : zéro erreur ou avertissement console, aucun débordement horizontal, cibles ≥ 48 px, toutes les images chargées avec un alt, les 8 × 3 liens contrôlés un par un contre l’ancienne page.
- **Captures** (hors site, non commitées) : `~/vitrine-testeurs/sortie/vitrine-<largeur>x<hauteur>.png` (page entière) et `…-ecran.png` (premier écran), plus `sortie/lighthouse-mobile.html`.
- **À noter** : les accroches et genres sont des textes rédigés pour la vitrine, à relire. Seuls Lockdown (16+) et Casino (18+) ont un badge d’âge, faute d’info pour les autres.
